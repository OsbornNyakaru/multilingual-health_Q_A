## Project summary and current goal
Post-close practice run of Zindi's **Multilingual Health Question Answering in Low-Resource African Languages Challenge**: answer maternal, sexual and reproductive health questions in Akan, Amharic, Luganda, Swahili and English (8 locale subsets). The score is 0.37 ROUGE-1 F1 + 0.37 ROUGE-L F1 + 0.26 LLM-judge. Submissions are unlimited, and only open-weight models with no paid APIs are allowed. **Current goal: beat the 11th-place reference approach (BGE-M3 retrieval → RAG-enriched LoRA fine-tune, plus the untried closed-pool vs generative router) on our own held-out eval, measured per subset.** Code is written locally; GPU work runs on molab. Every experiment follows the loop: hypothesis → single change → run → score locally per language → log here → keep or revert → submit only on a real margin (≥ +0.003, [[D-005-held-out-protocol]]).

## Current best
The live record is `experiments/RESULTS.md` (generated by `scripts/exp.py pull`; protocol in [[D-007-autoresearch-loop-on-molab]]): the best run per subset and the composite, test-mix weighted, on held-out and Val.

As of 2026-10-07: composite **held-out 0.4404 / Val 0.432** test-mix (ROUGE-only, max 0.74); per-subset holders in `experiments/RESULTS.md` (first baseline: [[EXP-007-ret-tfidfchar-nhall-vall]]). Older numbers ([[EXP-004-bge-m3-retrieval-heldout]] 0.3700 on a different 1,491-row split, unweighted) are not comparable. **Leaderboard best (2026-10-07, submission #6): public 0.66543 / private 0.65156** (public R1 0.6409, RL 0.594, judge 0.802): answer-aware fine-tuned selector (EXP-051) on Lug_Uga/Eng_Uga, rescoring (EXP-053) on Eng_Uga/Eng_Ken/Swa_Ken, fine-tuned Qwen on Eng_Gha/Eng_Eth, retrieval on Aka_Gha/Amh_Eth. Earlier: #5 0.64670 / 0.64048, #4 0.63133 / 0.63655, #3 0.62593 / 0.63170, #2 0.61423 / 0.60142, #1 0.59202 / 0.58162. Winners (final results, 2026-09-10): 0.7292 / 0.7291 / 0.7290; the gap is mostly answer selection on the repeated-answer subsets (plan: selection first). An uppercase probe confirmed the grader's ROUGE is case-sensitive whitespace, like ours ([[H-013-whitespace-tokenizer-matches-grader]], confirmed); LB ROUGE runs about 0.02 above local Val test-mix, most likely because test retrieves from Train + Val.

## How we run experiments on molab
- `autoresearch_nlp/program.md`: the experiment loop (spec → HF queue → `notebooks/molab_runner.py` → `scripts/exp.py pull`), how runs are judged, and the prioritised queue.
- `docs/molab_runbook.md`: the 3-step molab session for the runner. The old manual runbook is in `archive/docs/`.
- `docs/notion_tracker_prompt.md`: Notion AI prompt that builds the shared "runs" database (the team's live log). Copy each finished run into an `experiments/EXP-xxx` note here.
