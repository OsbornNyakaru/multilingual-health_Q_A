## Molab (remote)

Molab persists only sidebar uploads and `mo.persistent_cache` ([[Molab Platform]]). Two options, use both:

1. **Sidebar upload (fast, first session).** In the molab file panel create `data/raw/` next to the notebook and upload the 4 CSVs (24 MB total). The notebook searches `./data/raw`, `../data/raw`, `./data`, `.` for `Train.csv` so either `data/raw/` or a flat upload works.
2. **Hugging Face private dataset (repeatable).** One-time: `huggingface-cli upload <you>/afro-health-qa-data data/raw --repo-type dataset --private`. In molab set `HF_TOKEN` and `HF_DATA_REPO` (secrets panel) and the notebook downloads the CSVs itself when it cannot find them. Same trick for outputs: submissions and adapters get pushed to `<you>/afro-health-qa-runs` so a 12-hour session kill loses nothing.

Layout on molab mirrors local so the same relative paths work:

```
<notebook dir>/
├── molab_afro_health_qa.py
├── data/raw/*.csv           ← uploaded once
├── data/processed/          ← splits, regenerated each session (deterministic, seed 1234)
├── submissions/             ← CSV + JSON sidecar + rolling checkpoint
├── models/<run>/            ← LoRA adapters
└── results.tsv              ← appended per run
```
